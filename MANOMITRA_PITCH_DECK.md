## Defensible Judge Q&A Guide (Strict Evaluation Ready)

1. **"Are you claiming to diagnose dementia?"**
   > *"No, Judge. We explicitly position MANOMITRA as an AI-assisted cognitive engagement and longitudinal monitoring platform, not a diagnostic system. We do not replace doctors or clinical exams. Our role is to provide daily non-pharmacological stimulation (supported by NICE Level 1A guidelines on CST) and capture objective performance telemetry so family caregivers have visibility into changes over time."*

2. **"How does the adaptive difficulty engine work?"**
   > *"We operate on two distinct layers. Locally at the edge, simple heuristics adjust task difficulty within a session guided by the Yerkes-Dodson Law to prevent frustration. In the cloud, our Python FastAPI microservice models multi-session reaction time drift and error clusters to calibrate tomorrow's baseline difficulty."*

3. **"What happens during poor connectivity?"**
   > *"MANOMITRA is architected as an offline-first PWA. Workbox caches the app shell, while IndexedDB stores games and routines locally. A senior can play 100% offline. Telemetry automatically syncs via an asynchronous background queue when connection resumes."*

4. **"How do you ensure data privacy under the DPDP Act 2023?"**
   > *"We employ a local-first design where routine ticks and game scores reside in client-side IndexedDB. When synced, data is encrypted via AES-256 with role-scoped JWT authentication and a 30-day automated right-to-erasure workflow."*

## SYSTEM ARCHITECTURE
### A modular, edge-first architecture ensuring uninterrupted access.

- **Senior Interaction**: 56px+ tactile buttons, voice guidance, zero typing.
- **Patient PWA**: React 19, Vite, Web Speech API, WebAuthn.
- **Local-First Storage (Edge)**: IndexedDB Cache & Queue (**100% Offline Path**).
- **API & Gateway**: Node.js, role-scoped JWT, DPDP-aligned data architecture.
- **AI & Database**: Python FastAPI microservice on Render + MongoDB Atlas (AES-256).
- **Caregiver Layer**: Web dashboard + Meta WhatsApp Cloud API webhooks.
